# vinylo_llama

iOS side of Vinylo's on-device translation (`vinylo/llama` channel): the official llama.cpp b11913
`llama.xcframework` (Metal) fetched by Swift Package Manager, and a C++ core shared with Android
(`Sources/VinyloLlmCore`, also compiled by `android/app/src/main/cpp/CMakeLists.txt`). iOS 16.4+.
